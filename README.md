Student Expense Tracker
A C program that records monthly expenses by category and compares total spending with a student’s budget.

Team details: Team number: 7 · Batch: 52 · Members: Gaurish, Kashika, Mayank
Objectives and features
- Record expenses under Food, Travel, Books, or Entertainment.
- Show category totals and total spending.
- Identify the highest-spending category.
- Report whether the budget was exceeded or how much remains.
Algorithm
1. Read the monthly budget and number of expenses.
2. For each expense, read its category and amount, then add it to that category’s total.
3. Calculate total spending and remaining budget.
4. Find the category with the highest total.
5. Print the summary and budget status.
C concepts used
Variables, scanf/`printf`, for loop, switch, if/else, arithmetic, and strcpy.
Compile and run
gcc expense_tracker.c -o expense_tracker
./expense_tracker
